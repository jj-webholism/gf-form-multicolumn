# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [4.1.0]
### Security
- Added form ID guard to reduce cross-form field-container interference.

### Fixed
- Restored Gravity Forms 2.10+ row-level grid behaviour for modern Gravity Forms markup.
- Resolved PHP 8+ fatal errors in class signatures in admin files.

- Rolled back GFMC-73 issue as this appeared to cause issues with removed layout elements.

## [3.1.0]
> **Note:** If upgrading from a previous version of this plugin, it may be necessary to activate the CSS for each form that uses the multiple column functionality. (See 4.0.6 for instructions).

### Added
- Form settings modified to allow the addition of a `.js` file that hides and shows the wrapper list element around conditional logic elements.
- Form settings modified to allow the plugin CSS file to be selectively enabled and disabled for inclusion.
- Included capability to define custom CSS classes for columns.
- Introduced form validation when saving to reduce unequal row start/end implementations.
- Introduced functionality to provide appropriate layout on AJAX-generated forms.

### Changed
- Changed terminology: "Column Start" and "Column End" renamed to "Row Start" and "Row End" respectively.
- Plugin now automatically removes form entries when the plugin is uninstalled.

### Fixed
- Corrected IE11 CSS styling that was improperly aligning columns.

## [3.0.3]
### Changed
- Altered CSS to be more specific with class naming implementation.

### Fixed
- Removed `echo` commands causing update issues from within Gutenberg pages.

## [3.0.2]
### Changed
- Re-release of version 3.0.0 code state.

## [3.0.1]
### Fixed
- Restored code to version 2.1.1 state, as version 3.0.0 was generating an Internal Server Error.

## [3.0.0]
### Changed
- Restructured how columns and rows are added to forms; native UI buttons are now integrated directly into the Gravity Forms interface.

### Fixed
- Resolved issues with displaying multiple forms on a single page.
- Corrected error handling when a form ID is not present in the shortcode.
- Applied CSS enhancements to properly align list elements.

## [2.1.1]
### Removed
- Removed code that had been temporarily used for testing multisite functionality in 2.1.0.

## [2.1.0]
> **Note:** The title of this plugin has changed in this version to align with WordPress naming conventions. It may appear in a new location in your plugin list.

### Added
- Introduced a new CSS style (`li[class*="column-count-1"] > div > ul`) to remove left padding and margin from the first column of each row, ensuring expected element alignment.

### Changed
- Updated the plugin title to align with WordPress naming recommendations.

### Fixed
- Resolved issues preventing the plugin from providing network-only functionality on multisite installations. Admins can now activate or deactivate it on individual network sites.

## [2.0.1]
### Fixed
- Altered code to accommodate web servers running PHP versions older than 5.4.

## [2.0.0]
### Added
- Introduced new feature allowing multiple rows. Individual rows will automatically split the columns they contain evenly.
